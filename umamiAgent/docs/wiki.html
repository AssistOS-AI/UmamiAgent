Umami Agent Documentation

umamiAgent

umamiAgent is the single Ploinky agent that packages the self-hosted analytics stack and exposes the declared reporting tools. Its supervisor owns PostgreSQL, Umami, the internal upstream MCP service, and AgentServer. Workspace users reach the dashboard through authenticated Router ingress, while tool callers use the Router-mediated MCP route. The public tool set does not include analytics administration or event ingestion.

AgentServer

AgentServer is the Ploinky-facing tool server on container port 7000. It publishes operations from mcp-config.json and requires the Router's per-tool secure-wire authorization. The internal Umami MCP server is a backend adapter rather than an alternate public endpoint. Calls through the generic additional-server dashboard relay cannot substitute for the canonical MCP route.

Publication ingress

The agent-owned ingress accepts dashboard traffic on container port 3000 and forwards it to Next.js on 127.0.0.1:3001. Ploinky publishes it under the fixed /base-agent-additional-server/umamiAgent/3000 prefix. The image builds that prefix into Umami assets, and the ingress restores it after Router stripping. A supplied forwarding prefix must match exactly. Headerless internal API and tracker calls use the same adapter, while port 3001 remains private loopback.

Read-only reporting

The reporting boundary allows analytics queries but prohibits public tools that mutate upstream Umami data, create websites, administer users or teams, or ingest events. Report generation is a local output operation within that boundary. It reads several analytics results, writes a Markdown deliverable, and returns its path. Reusing a sanitized report label replaces the corresponding local file without changing the upstream analytics.

Umami Settings

Umami Settings is the AchillesIDE workspace settings plugin under IDE-plugins/umami-settings/. Operators select an existing website from the MCP-loaded list and provide its browser-reachable Umami URL. The plugin generates a snippet loading that URL's /script.js with the selected website identifier. Events go directly to Umami. Static plugin assets have an explicit guest route, which does not grant guest access to analytics MCP tools.
